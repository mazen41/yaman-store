# Audio Assets for Scanner Feedback

This directory contains audio files for scanner feedback:

- success.mp3 - Success sound (short beep/chime)
- error.mp3 - Error sound (low buzz)
- warning.mp3 - Warning sound (double beep)

## Instructions

Add short audio files (under 1 second) for optimal performance:
- success.mp3: A pleasant chime or beep for successful scans
- error.mp3: A low buzz for errors/not found
- warning.mp3: A double beep for warnings (already scanned)

## Note

If audio files are not available, the app will fall back to vibration feedback automatically.

## Audio File Requirements

- Format: MP3
- Duration: Under 1 second
- Volume: Moderate (not too loud)
- Quality: Standard (128kbps is sufficient)
